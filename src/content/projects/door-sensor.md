## 一句话

一块纽扣电池要撑一年的门磁：难点不在功能，而在**每一个微安**。

> 项目进行中。下面是已完成的部分和当前的卡点，目标是把"低功耗设计"这件事真正做一遍，而不是停留在"知道要休眠"。

## 目标与验收标准

| 维度 | 目标 |
| --- | --- |
| 续航 | CR2032（220mAh）撑 12 个月 |
| 休眠电流 | ≤ 3µA（整机，含 LDO 静态电流） |
| 唤醒方式 | 干簧管中断 + 定时心跳 |
| 通信 | LoRa，空旷 5km，室内穿 3 层墙 |
| 成本 | ≤ 45 元 |

## 已完成

- **硬件**：STM32L051C8T6 + SX1278 + 干簧管 + CR2032 电池座，第一版 PCB 已打样（两层，30×50mm）。
- **固件**：STOP 模式 + RTC 唤醒 + 外部中断唤醒的框架跑通，休眠电流实测 **2.1µA**。
- **通信**：LoRa 点对点收发正常，空旷实测 3.2km（目标 5km，还没到）。

![第一版 PCB](/img/pcb-door.svg)

*第一版：留了 SWD 调试口和电流测量跳线帽，方便用万用表串进去量功耗。*

## 当前的坑

**1. LDO 静态电流吃掉了大半预算**

现象：MCU 已经进 STOP 模式，整机还是 8µA。
原因：选的 LDO 静态电流 5µA，比 MCU 休眠电流还大。
下一步：换静态电流 1µA 以下的型号，或者干脆去掉 LDO 用 MCU 直接扛 3V。

**2. 干簧管误触发**

现象：门关着也会偶尔上报。
原因：中断脚没有 RC 消抖，旁边 LoRa 发射时的干扰串进来了。
下一步：加 100nF + 10k 硬件消抖，软件上做 50ms 窗口确认。

**3. 发射距离不够**

现象：空旷 3.2km，低于目标 5km。
下一步：天线做匹配、板边净空、发射功率从 17dBm 提到 20dBm 试试。

## 下一步计划

1. 换 LDO、改消抖电路，出第二版板（预计 11 月打样）；
2. 用电流探头做一次全流程功耗分解：休眠 / 唤醒 / 采样 / 发射各占多少；
3. 补一个 30 天连续运行测试，用实测数据反推续航。
