## 一句话

一个标准的课程设计题目，我没有停在"能跑"，而是把 PID 从"抄参数"调到"能解释每个参数为什么是这个值"。

## 背景与目标

课程要求：小车沿黑线跑完一圈。原始目标只是"不脱线"。

我给自己加了两个目标：

1. 单圈时间进入 20s 以内（初始版本 26s）；
2. 直道偏差控制在 ±5mm，弯道不切角。

## 我的角色

独立完成。硬件选型、焊接、固件、调参全是我一个人。

## 硬件设计

| 模块 | 型号 | 备注 |
| --- | --- | --- |
| 主控 | STM32F103C8T6 最小系统板 | 直接插在自制底板上 |
| 电机驱动 | TB6612FNG | 比 L298N 效率高、发热小 |
| 循迹 | 5 路灰度传感器（TCRT5000） | 模拟量输出，比数字量能更早发现偏移 |
| 测速 | 霍尔编码器（13 线）× 2 | 减速比 1:30 |
| 电源 | 2 节 18650 串联 → LM2596 降压 | 电机 7.4V、逻辑 5V 分开供 |

关键设计：**电机电源和逻辑电源分开走**，地线单点汇合——第一版共地噪声导致编码器计数乱跳，改了之后才稳定。

![主控底板 PCB](/img/pcb-car.svg)

*底板：把 STM32、TB6612、传感器接口和电源做在一块板上，避免杜邦线接触不良。*

## 控制思路

```c
/* 每 10ms 执行一次 */
err  = target_speed - encoder_speed;        // 速度环
pid  += Kp*err + Ki*(err - err_last) + Kd*(err - 2*err_last + err_prev);
bias = gray_weighted_position();            // 5 路灰度加权求偏移
steer = Kp_turn * bias + Kd_turn * (bias - bias_last);   // 转向环
motor_set(pid + steer, pid - steer);        // 差速
```

串级结构：**内环速度、外环转向**。速度环 10ms，转向环 20ms。

## 三个难点与解法

**1. 直道画龙（左右摆动）**

现象：直道上小车左右摆，速度越快越明显。
原因：Kp_turn 给太大，系统在等幅振荡。
解决：先只给 P，加到刚好开始振荡，再退回 60%；然后加 D 抑制超调。
效果：直道偏差从 ±20mm 降到 ±5mm。

**2. 弯道切角冲出赛道**

现象：急弯处直接切出去。
原因：转向环周期 20ms 太慢，加上速度没降。
解决：把灰度传感器的模拟量做加权平均（而不是离散判断），能提前约 15ms 感知偏移；同时在弯道自动降速 40%。
效果：连续跑 20 圈不脱线。

**3. 编码器计数偶发跳变**

现象：速度环偶尔输出尖峰，小车一顿一顿。
原因：电机换向时地弹噪声串进编码器信号线。
解决：编码器线加 RC 滤波 + 双绞；软件上做 3 点中值滤波。
效果：速度曲线平滑，跳变消失。

## 结果

| 指标 | 初始 | 最终 |
| --- | --- | --- |
| 单圈时间 | 26.0s | 18.4s |
| 直道偏差 | ±20mm | ±5mm |
| 连续跑圈 | 3 圈后脱线 | 20 圈无脱线 |

## 如果重做一次

- 布线阶段就该把电机线和信号线分开，而不是出了问题再飞线。
- 调参应该写个上位机实时看曲线，靠肉眼盯着小车调太慢。
